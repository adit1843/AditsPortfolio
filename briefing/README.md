# Daily Brief V1

This folder is an isolated prototype for a personalized text briefing.

Current prototype capabilities:
- Today's briefing
- Archive placeholder / coverage memory concept
- Separate on-demand explainers
- Knowledge graph confidence
- Preferences / interest profile
- Post-brief survey
- Local browser persistence for prototype feedback

Important product rule: requesting an explainer does not alter future story selection.

Next integrations:
- live current-news research
- server-side generation
- persistent database
- email survey delivery
- Vercel environment variables / API key
- later: text-to-speech
