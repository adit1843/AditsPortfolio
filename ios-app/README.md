# Neosis for iPhone — phase 1

Native iOS project scaffold, separate from the production website. The initial bundled screen is a branded launcher; it is **not yet an App Store/TestFlight-ready Neosis app**.

## Prerequisites

- Mac with Xcode 26+ and command-line tools, Node.js 22+
- Apple Developer Program membership for TestFlight distribution

## Run the starter on iPhone simulator

```sh
cd ios-app
npm install
npx cap add ios
npx cap sync ios
npx cap open ios
```

Choose a simulator in Xcode, then Run. Native iOS project files are generated by Capacitor on the Mac.

## Test the existing live Neosis app during development

To load the current authenticated web experience inside a development-only Capacitor WebView, temporarily copy `capacitor.dev.config.ts` to `capacitor.config.ts` **locally** before `npx cap sync ios`. Restore the release-safe config before committing, archiving, or distributing the app. Capacitor warns `server.url` is only for development; it is unsuitable for App Store production.

## Before TestFlight

1. Bundle the mobile Neosis UI locally, replacing this starter screen.
2. Migrate API calls, cookie/session handling, routing, and account flows from same-origin web endpoints to an explicit mobile-safe auth/API strategy; test OAuth deep links.
3. Implement native/background audio, Now Playing, interruption handling, and safe-area navigation.
4. Produce the 1024×1024 icon, launch assets, screenshots, privacy disclosure, and account-deletion flow.
5. Confirm bundle ID, Apple team, signing, entitlement requirements, and archive with Xcode. Upload via Xcode Organizer to App Store Connect, then TestFlight.

Production website source and Vercel settings are intentionally unchanged.
